# Документация CogniBoiler

Индекс документов. Здесь живёт **состояние проекта** — то, что должно пережить потерю
любого чата и смену любой модели.

## Внутренние документы (здесь, `docs/__arch__/`, по-русски)

| Файл | Отвечает на вопрос |
|---|---|
| `VISION.txt` | Каким проект должен стать к версии 1.0 без ИИ: границы, требования, демо, критерии |
| `ROADMAP.md` | Что строим, в каком порядке, что уже готово, известные дефекты |
| `open-questions.md` | Решения владельца и открытые вопросы |
| `archive/` | Устаревшие планы, сохранённые для истории |

## В корне репозитория

| Файл | Отвечает на вопрос |
|---|---|
| `AGENTS.md` | Правила для ИИ-агентов (сгенерированный свод) |
| `CLAUDE.md` | Точка входа Claude Code |
| `task-checklist.md` | Текущая или последняя задача |

## Внешние документы (по-английски)

| Файл | Отвечает на вопрос |
|---|---|
| `README.md` (корень) | Что это, как запустить — точка входа |
| `docs/architecture/overview.md` | Что **реально** построено в коде прямо сейчас |
| `docs/architecture/invariants.md` | Что нельзя ломать никогда |
| `docs/architecture/service-boundaries.md` | Какой сервис чем владеет |

## Правило актуальности

Если план, документ состояния и код противоречат друг другу — **код является фактом, план
является намерением**. Расхождение устраняется в той же задаче либо явно сообщается.
